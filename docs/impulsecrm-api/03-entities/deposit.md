# Депозит — сущность `deposit`

[← Оглавление](../README.md) · [Индекс сущностей](README.md)

Операции по депозиту клиента: пополнение, списание, история. Отдельной карточки депозита нет — баланс хранится в клиенте (`client.deposit`).

> **Проверено на демо-контуре 2026-11-19.** `delete` принимает только одну операцию за вызов (>1 → 500 «Можно удалить только 1 операцию.»); удаление операции откатывает баланс. Подробности — в [07-verification.md](../07-verification.md).

|---|---|---|---|
| [Список (выборка)](#list) | `POST` | `/api/public/deposit/list` | Получить список операций по депозиту |

## Список (выборка)

`POST /api/public/deposit/list`

_Получить список операций по депозиту_

Возвращает список операций по депозиту: объект с полями total (количество в выборке) и items (массив записей).

В теле запроса в объекте filters передайте client_id — числовой идентификатор клиента в CRM.

### Тело запроса

| Поле | Тип | Обязательное | Описание | Пример |
|---|---|---|---|---|
| `fields` | `array` | — | Какие колонки выгружать. Если не указать, то все записи выгрузятся. | `["id", "sum"]` |
| `limit` | `number` | — | Сколько записей выгружать за одну страницу | `10` |
| `page` | `number` | — | Номер страницы (начиная с 1) | `1` |
| `sort` | `object` | — | Сортировка | `{"created": "desc"}` |
| `filters` | `object` | — | Фильтрация. Для списка депозитов клиента укажите client_id — идентификатор клиента в CRM. | `{"client_id": 1}` |
| `columns` | `object` | — | Фильтрация по значению полей в уже полученной выборке | `[]` |

Пример тела запроса:

```json
{
  "limit": 10,
  "page": 1,
  "sort": {
    "created": "desc"
  }
}
```

Полный набор параметров выборки (`fields`, `limit`, `page`, `sort`, `filters`, `columns`) и правила фильтрации — в разделе [«Действие list»](../02-actions.md#list).

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `total` | `number` | Общее количество записей в выборке |
| `items` | `array` | Массив записей депозита. Структура одного элемента — в таблице выше в тексте раздела. |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/deposit/list" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"limit": 10, "page": 1, "sort": {"created": "desc"}}'
```

<a id="input"></a>
## Пополнить депозит

`POST /api/public/deposit/input`

_Пополнение депозита_

Внесение средств на депозит клиента.

### Тело запроса

| Поле | Тип | Обязательное | Описание | Пример |
|---|---|---|---|---|
| `sum` | `number` | да | Сумма операции по депозиту | `100` |
| `payment` | `number` | да | Код способа оплаты (1 - наличные, 2 - карта) | `1` |
| `date` | `number` | — | Дата операции (Unix timestamp) | `null` |
| `debt` | `boolean` | да | Признак долга / задолженности по операции | `false` |
| `annotation` | `string` | — | Текст примечания к операции | `null` |
| `client_id` | `number` | да | Идентификатор клиента в CRM, для которого вводится операция | `1` |

Пример тела запроса:

```json
{
  "sum": 100,
  "payment": 1,
  "debt": false,
  "client_id": 1
}
```

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `kkt` | `object` | Объект чека (если подключена касса) |
| `success` | `boolean` | Статус операции: true — успешно, false — ошибка |
| `id` | `number` | Идентификатор записи депозита после операции |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/deposit/input" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"sum": 100, "payment": 1, "debt": false, "client_id": 1}'
```

<a id="delete"></a>
## Удалить

`POST /api/public/deposit/delete`

_Удалить записи операций по депозиту_

Удаляет одну или несколько записей операций по депозиту в CRM.

### Тело запроса

Тело — JSON-массив идентификаторов: Идентификатор зала в корневом массиве тела запроса. Можно передать один или несколько id за один запрос.

```json
[1]
```

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `success` | `boolean` | Статус операции: true — успешно, false — ошибка |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/deposit/delete" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '[1]'
```
