# Индивидуальный абонемент — сущность `individual_account`

[← Оглавление](../README.md) · [Индекс сущностей](README.md)

Индивидуальный абонемент клиента.

> **Проверено на демо-контуре 2026-11-19.** Для создания нужны `number`, `payBox`, `shift`, `pays`. Подробности — в [07-verification.md](../07-verification.md).

**Значение поля `entity`:** `individualAccount`

## Действия

| Действие | Метод | Путь | Описание |
|---|---|---|---|
| [Получить по идентификатору](#get) | `GET` | `/api/public/individual_account/load/{id}` | Получить индивидуальный абонемент по идентификатору |
| [Список (выборка)](#list) | `POST` | `/api/public/individual_account/list` | Получить список индивидуальных абонементов |
| [Создать](#create) | `POST` | `/api/public/individual_account/update` | Создать индивидуальный абонемент |
| [Обновить](#update) | `POST` | `/api/public/individual_account/update` | Обновить индивидуальный абонемент |
| [Удалить](#delete) | `POST` | `/api/public/individual_account/delete` | Удалить индивидуальные абонементы |

## Получить по идентификатору

`GET /api/public/individual_account/load/{id}`

_Получить индивидуальный абонемент по идентификатору_

Возвращает информацию об индивидуальном абонементе по идентификатору из CRM.

### Параметры пути

| Параметр | Тип | Описание | Пример |
|---|---|---|---|
| `id` | `number` | Идентификатор индивидуального абонемента | `1` |

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `style` | `object` | Объект направления, которое закреплено за индивидуальным абонементом |
| `teacher` | `object` | Объект преподавателя, который закреплен за индивидуальным абонементом |
| `number` | `number` | Внутренний номер абонемента |
| `trainings` | `number` | Количество занятий по абонементу(или минут, если абонемент часовой) |
| `trainingsTotal` | `number` | Общее количество занятий (Количество занятий по абонементу + количество подарочных занятий) |
| `trainingsUsed` | `number` | Количество использованных занятий абонемента (или минут, если абонемент часовой) |
| `trainingsLeft` | `number` | Количество оставшихся занятий абонемента (или минут, если абонемент часовой) |
| `inMinutes` | `boolean` | Является ли абонемент часовым |
| `inMoney` | `boolean` | Является ли абонемент денежным (фитнес-шеринг) |
| `gift` | `number` | Количество подарочных занятий(или минут, если абонемент часовой) |
| `days` | `number` | Срок действия абонемента (количество дней), для бессрочного абонемента -1 |
| `daysTotal` | `number` | Общий срок действия (количество дней) |
| `daysLeft` | `number` | Оставшийся срок действия (количество дней) |
| `prolongDays` | `number` | Количество дней продления |
| `freezeDays` | `number` | Количество дней заморозки |

| `endDate` | `number` | Дата окончания действия (UTC) |

| `minutesEnd` | `number` | Время окончания действия абонемента (минуты). Используется если абонемент действует только в определённые часы |
| `device` | `array` | Устройства СКУД (массив идентификаторов устройств) |
| `free` | `boolean` | Признак пробного абонемента |

| `settings` | `object` | Объект настроек абонемента |
| `clientSubscription` | `object` | Объект подписки клиента на абонемент. (Если подключены рекуррентные платежи) |

| `notBegin` | `boolean` | Признак того, что абонемент еще не начался |
| `freeze` | `boolean` | Признак того, что абонемент сейчас заморожен |

## Список (выборка)

`POST /api/public/individual_account/list`

_Получить список индивидуальных абонементов_

Возвращает массив индивидуальных абонементов из CRM.

### Тело запроса

| Поле | Тип | Обязательное | Описание | Пример |
|---|---|---|---|---|
| `fields` | `array` | — | Какие колонки выгружать. Если не указать, то все записи выгрузятся. | `["id", "entity", "client"]` |
| `limit` | `number` | — | Сколько записей выгружать. Если не указать, то все записи выгрузятся | `10` |
| `page` | `number` | — | Какую страницу выборки выгружать | `1` |
| `sort` | `object` | — | По какой колонке сортировать | `{"created": "desc"}` |
| `filters` | `object` | — | Фильтрация по свойствам | `[]` |
| `columns` | `object` | — | Фильтрация значению (например по периоду создания) | `[]` |

Пример тела запроса:

```json
{
  "limit": 10,
  "page": 1,
  "sort": {
    "created": "desc"
  }
}
```

Полный набор параметров выборки (`fields`, `limit`, `page`, `sort`, `filters`, `columns`) и правила фильтрации — в разделе [«Действие list»](../02-actions.md#list).

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `total` | `number` | Общее количество индивидуальных абонементов в выборке |
| `items` | `array` | Массив с описанием индивидуальных абонементов (описание зависит от параметров fields) |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/individual_account/list" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"limit": 10, "page": 1, "sort": {"created": "desc"}}'
```

## Удалить

`POST /api/public/individual_account/delete`

_Удалить индивидуальные абонементы_

Удаляет индивидуальные абонементы в CRM.

Позволяет удалить как один индивидуальный абонемент, так и несколько.

### Тело запроса

Тело — JSON-массив идентификаторов: Идентификатор индивидуального абонемента в корневом массиве тела запроса. Можно передать один или несколько id за один запрос.

```json
[1]
```

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `success` | `boolean` | Статус операции: true — успешно, false — ошибка |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/individual_account/delete" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '[1]'
```
