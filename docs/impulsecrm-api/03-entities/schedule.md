# Расписание — сущность `schedule`

[← Оглавление](../README.md) · [Индекс сущностей](README.md)

Занятие в расписании: зал, группа/преподаватель/клиент, день недели или разовая дата, время, тип.

> **Проверено на демо-контуре 2026-11-19.** Создание в занятое время → 200 + `success: false` с текстом конфликта; `delete` — `{item, date}`; удаление логическое. Подробности — в [07-verification.md](../07-verification.md).

## Действия

| Действие | Метод | Путь | Описание |
|---|---|---|---|
| [Получить по идентификатору](#get) | `GET` | `/api/public/schedule/load/{id}` | Получить занятие из расписания по идентификатору |
| [Список (выборка)](#list) | `POST` | `/api/public/schedule/list` | Получить список занятий в расписании |
| [Создать](#create) | `POST` | `/api/public/schedule/update` | Создать занятие в расписании |
| [Обновить](#update) | `POST` | `/api/public/schedule/update` | Обновить занятие в расписании |
| [Удалить](#delete) | `POST` | `/api/public/schedule/delete` | Удалить занятие из расписания |

<a id="get"></a>
## Получить по идентификатору

`GET /api/public/schedule/load/{id}`

_Получить занятие из расписания по идентификатору_

Возвращает информацию о занятии в расписании по идентификатору из CRM.

### Параметры пути

| Параметр | Тип | Описание | Пример |
|---|---|---|---|
| `id` | `number` | Идентификатор занятия в расписании | `1` |

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `group` | `object` | Объект группы занятия (Заполнен если занятие грпповое) |
| `teacher1` | `object` | Первый преподаватель (Заполнен если занятие грпповое) |
| `teacher2` | `object` | Второй преподаватель (Заполнен если занятие грпповое и группу ведёт несколько преподавателей) |
| `style` | `object` | Направление (Заполнено если занятие индивидуальное и выбрано направление) |
| `teacher` | `object` | Преподаватель (Заполнено если занятие индивидуальное) |
| `client` | `object` | Клиент (Заполнено если занятие индивидуальное/аренда) |
| `target` | `object` | Целевой объект занятия (группа/преподаватель/зал) |
| `regular` | `boolean` | Признак регулярности занятия |
| `date` | `number` | Дата занятия (Unix timestamp. Заполнено если занятие не регулярное, а разовое) |
| `dateBegin` | `number` | Дата начала периода провердения занятия (Unix timestamp. Заполнено если зантяие регулярное) |
| `dateEnd` | `number` | Дата окончания периода провердения занятия (Unix timestamp, Заполнено если занятие регулярное и занятие ограничено периодом) |
| `day` | `number` | День недели занятия (Заполнено если зантяие регулярное. 1 - понедельник, 2 - вторник, 3 - среда, 4 - четверг...) |
| `minutesBegin` | `number` | Время начала занятия в минутах от начала суток |
| `minutesEnd` | `number` | Время окончания занятия в минутах от начала суток |
| `color` | `string` | Цвет записи в расписании (в формате hex без символа #) |
| `type` | `number` | Тип записи расписания (0 - групповое, 1 - индивидуальное, 2 - аренда) |
| `note` | `string` | Комментарий к записи |
| `payment` | `object` | Индивидуальные настройки приема платежей |
| `wage` | `number` | Сумма начисления преподавателю в ЗП |
| `hall` | `object` | Объект зала, в котором проводится занятие |
| `typeTitle` | `string` | Текстовое название типа занятия (Группа/Индивидуальное занятие/Аренда) |
| `created` | `number` | Время создания записи (Unix timestamp) |
| `creator` | `object` | Пользователь, создавший запись |
| `branch` | `object` | Объект филиала |
| `id` | `number` | Идентификатор записи расписания |
| `entity` | `string` | Тип сущности, для расписания — schedule |
| `deleted` | `boolean` | Признак удаления записи расписания (или null) |

### Пример вызова

```bash
curl -s -g "$IMPULSE_BASE_URL/api/public/schedule/load/1" \
  -H "Authorization: Basic $IMPULSE_API_KEY"
```

<a id="list"></a>
## Список (выборка)

`POST /api/public/schedule/list`

_Получить список занятий в расписании_

Возвращает массив занятий в расписании из CRM.

### Тело запроса

| Поле | Тип | Обязательное | Описание | Пример |
|---|---|---|---|---|
| `fields` | `array` | — | Какие колонки выгружать. Если не указать, то все записи выгрузятся. | `["id", "target", "typeTitle"]` |
| `limit` | `number` | — | Сколько записей выгружать. Если не указать, то все записи выгрузятся | `10` |
| `page` | `number` | — | Какую страницу выборки выгружать | `1` |
| `sort` | `object` | — | По какой колонке сортировать | `{"created": "desc"}` |
| `filters` | `object` | — | Фильтрация по свойствам | `{"branch": {"id": 1}}` |
| `columns` | `object` | — | Фильтрация значению (например по периоду создания) | `[]` |

Пример тела запроса:

```json
{
  "limit": 10,
  "page": 1,
  "sort": {
    "created": "desc"
  }
}
```

Полный набор параметров выборки (`fields`, `limit`, `page`, `sort`, `filters`, `columns`) и правила фильтрации — в разделе [«Действие list»](../02-actions.md#list).

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `total` | `number` | Общее количество занятий расписания в выборке |
| `items` | `array` | Массив с описанием занятий расписаня (описание зависит от параметров fields) |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/schedule/list" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"limit": 10, "page": 1, "sort": {"created": "desc"}}'
```

## Создать

`POST /api/public/schedule/update`

_Создать занятие в расписании_

Создает новое занятие в расписании CRM.

### Тело запроса

| Поле | Тип | Обязательное | Описание | Пример |
|---|---|---|---|---|
| `hall` | `object` | да | Объект зала (Внутри можно передать только id) | `{"id": 6}` |
| `group` | `object` | — | Объект группы (Обязательно для групповых занятий. Внутри можно передать только id) | `{"id": 11}` |
| `teacher` | `object` | — | Объект преподавателя (Обязательно для индивидуальных занятий. Внутри можно передать только id) | `null` |
| `style` | `object` | — | Объект направления (Заполняется если индивидуальное занятие на определённое напрваление. Внутри можно передать только id) | `null` |
| `client` | `object` | — | Объект клиента (Обязательно для индивидуальных занятий/аренды. Внутри можно передать только id) | `null` |
| `regular` | `boolean` | — | Признак регулярной записи расписания | `true` |
| `date` | `number` | — | Дата записи (Unix timestamp. Заполняется если занятие не регулярное, а разовое) | `1775174400` |
| `dateBegin` | `number` | — | Дата начала периода (Unix timestamp. Заполняется если занятие регулярное) | `1775174400` |
| `dateEnd` | `number` | — | Дата окончания периода (Unix timestamp. Заполняется если занятие регулярное и занятие нужно ограничить периодом) | `1775178000` |
| `day` | `number` | да | День недели записи (Заполняется если занятие регулярное. 1 - понедельник, 2 - вторник, 3 - среда, 4 - четверг...) | `5` |
| `minutesBegin` | `number` | да | Время начала в минутах от начала суток | `960` |
| `minutesEnd` | `number` | да | Время окончания в минутах от начала суток | `1020` |
| `type` | `number` | да | Тип записи расписания (0 - групповое, 1 - индивидуальное, 2 - аренда) | `0` |
| `wage` | `number` | — | Сумма начисления преподавателю в ЗП | `null` |
| `note` | `string` | — | Комментарий к записи | `null` |
| `color` | `string` | да | Цвет записи расписания | `"ffd966"` |
| `teacher1` | `object` | — | Первый преподаватель (Обязательно для групповых занятий. Внутри можно передать только id) | `{"id": 4}` |
| `teacher2` | `object` | — | Второй преподаватель (Обязательно для групповых занятий, если группу ведёт несколько преподавателей. Внутри можно передать только id) | `{"id": 5}` |

Пример тела запроса:

```json
{
  "hall": {
    "id": 6
  },
  "group": {
    "id": 11
  },
  "regular": true,
  "date": 1775174400,
  "dateBegin": 1775174400,
  "dateEnd": 1775178000,
  "day": 5,
  "minutesBegin": 960,
  "minutesEnd": 1020,
  "type": 0,
  "color": "ffd966",
  "teacher1": {
    "id": 4
  },
  "teacher2": {
    "id": 5
  }
}
```

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `success` | `boolean` | Статус операции: true — успешно, false — ошибка |
| `id` | `number` | Идентификатор созданного занятия в расписании |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/schedule/update" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"hall": {"id": 6}, "group": {"id": 11}, "regular": true, "date": 1775174400, "dateBegin": 1775174400, "dateEnd": 1775178000, "day": 5, "minutesBegin": 960, "minutesEnd": 1020, "type": 0, "color": "ffd966", "teacher1": {"id": 4}, "teacher2": {"id": 5}}'
```

## Удалить

`POST /api/public/schedule/delete`

_Удалить занятие из расписания_

Удаляет занятие из расписания в CRM.

### Тело запроса

| Поле | Тип | Обязательное | Описание | Пример |
|---|---|---|---|---|
| `date` | `number` | — | Дата удаления занятия (Unix timestamp) | `1775174400` |
| `item` | `object` | да | Объект занятия в расписании (Внутри можно передать только id) | `{"id": 119, "entity": "schedule"}` |

Пример тела запроса:

```json
{
  "date": 1775174400,
  "item": {
    "id": 119,
    "entity": "schedule"
  }
}
```

### Ответ

| Поле | Тип | Описание |
|---|---|---|
| `success` | `boolean` | Статус операции: true — успешно, false — ошибка |

### Пример вызова

```bash
curl -s -X POST "$IMPULSE_BASE_URL/api/public/schedule/delete" \
  -H "Authorization: Basic $IMPULSE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"date": 1775174400, "item": {"id": 119, "entity": "schedule"}}'
```
