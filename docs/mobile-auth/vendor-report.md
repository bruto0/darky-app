## Кратко

В контуре `https://<tenant>.impulsemini.ru` (виджет `/widget/2`, «Личный кабинет клиента»)
обнаружены проблемы, которые позволяют получить доступ к личному кабинету **любого**
клиента, зная только его номер телефона, а также получить хеши паролей и персональные
данные клиентов без аутентификации. Ниже — воспроизведение, влияние и предложения по
исправлению.

## 1. Критично: `client secret` выдаётся по одному номеру телефона

**Где:** `POST /api/public/widget_schedule/phone_info`, `POST /api/public/widget_client_lk/search`
**Что происходит:** клиентский ЛК авторизуется парой `client_id` + `secret` (64 hex-символа),
которая передаётся в теле каждого запроса (`{"filters":{"client_id":…,"secret":…}}`).
Метод `search` возвращает эту пару по одному номеру телефона — **без пароля и без сессии**:

```
POST /api/public/widget_client_lk/search
Content-Type: application/json

"{\"phone\":\"<phone-encoded>\",\"socialPage\":null}"
```

Ответ (после декодирования) содержит `id`, `secret` и профиль клиента. Дальше с этой парой
читаются абонементы, посещения, депозиты, бонусы, брони и штрихкод:

```
POST /api/public/widget_client_lk/accounts
Content-Type: application/json

"{\"filters\":{\"client_id\":<id>,\"secret\":\"<secret>\"}}"
```

**Влияние:** обход аутентификации. Номер телефона — публичный идентификатор; перебором или
по утечке базы клиентов можно получить доступ к ЛК любого клиента, включая финансовые
данные (депозит, бонусы, история платежей).

**Предложение:** не возвращать `secret` в `search`; выдавать короткоживущий токен только
после успешной проверки пароля/кода; привязать токен к устройству и сессии; ограничить
частоту запросов `search`/`phone_info`.

## 2. Высоко: в ответе `search` возвращается bcrypt-хеш пароля клиента

В том же ответе присутствует поле `settings.password` вида `$2y$10$…`.
**Влияние:** офлайн-подбор пароля при утечке ответа (а он доступен без аутентификации,
см. п. 1); пароли, совпадающие с другими сервисами, компрометируются.
**Предложение:** исключить `password` (и любые хеши) из ответов API; при необходимости
отдавать только флаг «пароль установлен».

## 3. Высоко: публичное расписание раскрывает персональные данные клиентов

`POST /api/public/widget_schedule/list` и `POST /api/public/widget_client_mobile/schedule`
отвечают **без авторизации** и содержат сетку занятий филиала. В записях индивидуальных
занятий (`type: 1`) и аренды (`type: 2`) приходит объект `client`:

```json
"client": {
  "id": 104, "lastName": "…", "name": "…", "middleName": "…",
  "status": {"name": "…", "pipeline": {…}}, "deposit": 1800, "bonus": 0,
  "rfm": …, "ltv": …, "fotoThumbUrl": "…"
}
```

**Влияние:** утечка ПДн (ФИО, статус, финансовые показатели) третьих лиц; возможность
сопоставить клиента с расписанием.
**Предложение:** отдавать в публичном расписании только `client.id` (или ничего), либо
экранировать ПДн; для внутренних нужд — отдельный авторизованный метод.

## 4. Средне: возможная SQL-инъекция в `widget_rent/rents`

Запрос `POST /api/public/widget_rent/rents` с пустым фильтром возвращает `500` с обрывком
SQL в тексте ошибки:

```
An exception occurred while executing 'select id from client where deleted is NULL AND ': …
```

Похоже, условия фильтра конкатенируются в запрос. Прошу проверить; при подтверждении —
параметризовать запросы. Дополнительно: текст ошибки раскрывает структуру запроса.

## 5. Прочее

- **CORS:** `Access-Control-Allow-Origin` отражает произвольный `Origin` — запросы к API
  можно делать с любого сайта.
- **Нет ограничения попыток** на `widget_schedule/check_password` и `user/login`
  (серия неверных попыток не блокируется).
- **Отладочная информация:** ответы `500` содержат стек, имена классов и абсолютные пути
  (`/var/www/.../api/src/Controller/...`).

## Как воспроизвести

1. `GET /api/public/widget/load/2` — конфиг виджета (без авторизации).
2. Закодировать телефон: `base64(reverse(base36(цифры + 49680531)))`.
3. `POST /api/public/widget_client_lk/search` с `{"phone":"<encoded>","socialPage":null}`
   (тело — дважды закодированный JSON) → `id` и `secret`.
4. `POST /api/public/widget_client_lk/accounts` с `{"filters":{"client_id":<id>,"secret":"<secret>"}}`.

Скрипты воспроизведения: `widget-probe.ps1`, `widget-surface.ps1` (в этом же каталоге).
